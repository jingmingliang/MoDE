# 📄Abstract
Compact feature representations are essential for deep neural networks, as they retain task-relevant information while reducing representational redundancy. Convolutional sparse coding (CSC) provides a principled framework for learning compact representations by expressing feature maps as sparse combinations of convolutional dictionary atoms. However, visual features exhibit both shared structural patterns and input-dependent variations across channels. In conventional CSC, different inputs are represented using the same dictionary, limiting its ability to adapt the underlying atoms to input-specific feature characteristics. This motivates a sparse representation framework that preserves shared dictionary structures while enabling input-conditioned adjustments to the dictionary. To address this challenge, we propose Mixture-of-Dictionary-Experts Convolutional Sparse Coding (MoDE-CSC), a channel-adaptive sparse representation module built upon a shared-plus-residual dictionary construction. A shared base dictionary captures reusable structures, while expert-specific residual dictionaries provide complementary adjustments to the shared atoms. A lightweight statistical router predicts expert combination weights from the statistics of individual input channels, enabling different channels within the same sample to assemble distinct input-conditioned dictionaries. The resulting multichannel dictionary is then used to obtain sparse representations through an unfolded iterative shrinkage-thresholding algorithm (ISTA), allowing dictionary adaptation and sparse inference to be jointly optimized within modern deep networks. Furthermore, a task-driven objective jointly optimizes downstream performance, expert load balancing, and dictionary diversity. Extensive experiments on image classification and object detection demonstrate the effectiveness and versatility of MoDE-CSC across different architectures.
